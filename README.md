# Sockpuppets-detection-in-wiki
This project investigates whether sockpuppet accounts on Hebrew Wikipedia behave differently from regular users within discussion networks. We built our own dataset by scraping Wikipedia's public sockpuppet investigation records (a table listing confirmed puppet-master/sockpuppet pairs) via the MediaWiki API and BeautifulSoup, then crawled the talk-page discussions each user participated in to reconstruct reply networks as directed graphs. For each discussion graph we computed structural and information-theoretic metrics (in/out-degree, reciprocity, centrality measures, clustering coefficient, PageRank, k-order Markov transition entropy, etc.) and used statistical tests (Mann–Whitney U) to compare sockpuppets, their masters, and regular users. Built with Python, requests/BeautifulSoup for scraping, NetworkX for graph construction/analysis, SciPy/NumPy for statistics, and Matplotlib/Seaborn for visualization.
